0. 前提
   手机和 Mac 同一 WiFi
   手机 未安装远控 App（干净测试先卸载）
   adb uninstall com.vibelink.client.debug
   adb uninstall com.vibelink.installer.debug
1. 查 Mac IP 并改配置
   Android_O/app/build.gradle.kts
   buildConfigField("String", "PAYLOAD_APK_URL", "\"http://192.168.1.100:3000/downloads/client.apk\"")

2. 编译远控 APK 并放到 API
      Android Studio 打开 Android/ → Build → Build APK(s)

    Debug 包路径类似：

Android/app/build/outputs/apk/debug/app-debug.apk
复制到 API 下载目录：

cp Android/app/build/outputs/apk/debug/app-debug.apk Manage/api/downloads/client.apk
重要： Debug 测试时

远控包名 = com.vibelink.client.debug
Android_O Debug 检测的也是 .debug
两边要一致。若放的是 release APK（com.vibelink.client），Android_O Debug 会一直认为「未安装」。
